## F-t5-L2-1: All T5 requirements met

I confirmed each requirement from the code and the tests. I did not run the tests myself, because Bash was denied. The evidence shows `cargo test -p nodemind-api --test auth` passed.
- AC-1.1: accept_invite claims the invite with an atomic UPDATE (used_at IS NULL, expires_at > now()) before it calls hash. A reused, expired or bogus token therefore returns 401 without hashing. No signup route exists, and the test checks four candidate URLs for 404. A concurrent-claim test expects one 200 and one 401.
- AC-1.2: the CurrentUser extractor returns 401 for a missing, unknown or expired session. The tests cover a missing cookie, garbage and expiry.
- Password length: 12–128 characters, counted with chars().count() and checked before claiming the invite. Login also rejects more than 128 characters before hashing, and the test covers 11/129 plus the inclusive 12 and 128 bounds.

- reset-password: one transaction deletes invites and sessions, nulls password_hash, inserts the password_reset tombstone and creates a new invite. It logs event=tombstone after commit. The test checks the log line and that it leaks neither the link nor the email.
- Storage: invite and session tokens are stored as SHA-256 bytea, and the test checks the stored length. Argon2 runs inside spawn_blocking.
- Interface: CurrentUser { id } is implemented as a FromRequestParts extractor and used by /api/me and the stand-in /api/canvases route.
